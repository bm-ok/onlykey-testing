onlykey-testing: nw.js session

This landing page makes no device call, deliberately. The web app's pages talk to the device as they load, and a page opened before the OnlyKey is unlocked has its startup OKCONNECT time out - which raises a native WebAuthn dialog that nothing on the CDP side can dismiss, wedging the session.

Tests open their own windows, after the device is up. See lib/gui.js.
